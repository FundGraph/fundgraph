# Development model

The repository is the source of truth. Work proceeds phase-by-phase: inspect state, read relevant docs, implement the smallest complete slice, test, update documentation/state, and verify acceptance criteria. Architecture decisions go in `DECISION_LOG.md`.

Codex is the primary engineering agent. Other assistants may help with scoped edits, but may not silently redefine architecture, evidence authority, security boundaries, or product scope.
