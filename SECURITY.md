# Security policy

FundGraph is a local analysis tool, not a payment or credential-management system. Do not include private source, tokens, credentials, or sensitive lockfiles in issues or reports.

Report suspected vulnerabilities privately to the repository maintainer once the project remote is established. Include reproduction steps, affected version or commit, impact, and a minimal safe sample. Do not publicly disclose an exploitable issue before coordinated remediation.

The security model and threat assumptions are maintained in [`docs/SECURITY.md`](docs/SECURITY.md).
