# Code of Conduct

FundGraph follows the Contributor Covenant, version 2.1. Participants must be respectful, inclusive, constructive, and truthful. Harassment, discrimination, doxxing, threats, malicious metadata, and deliberate misrepresentation are not acceptable.

Report unacceptable behavior privately to the project maintainers. Until maintainers and contact details are published, use the repository owner’s private contact channel rather than public issue discussion.
